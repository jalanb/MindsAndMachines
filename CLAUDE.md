# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Repository Purpose

This is a study notes repository for MIT's **Minds and Machines** online course (24.09x).

Course URL: https://mitxonline.mit.edu/courses/course-v1:MITxT+24.09x/

## Repository Structure

- **`docs/`** - Markdown files extracted from course platform:
  - `welcome.md` - Latest course announcements from instructor (Patrick)
  - `dates.md` - Assignment deadlines and exam dates
  - `part 1.md` / `part 2.md` - Course content structure
  - `reading.md` - Complete reading list
  - `Signed up.md` - Enrollment confirmation

- **`sessions/`** - Study session notes, timestamped as `YYYY-MM-DD-HH-MM-SS.md`
  - Each session file documents progress, insights, and planning
  - Session files track which lectures/readings have been completed
  - Use these to maintain continuity between study sessions

## Course Structure

**Part 1 - Minds and Computers** (Lectures 1-6)
- Chinese Room argument, Turing Test, Arguments

**Part 2 - From Dualism to Functionalism** (Lectures 7-13)
- Dualism, Behaviorism, Identity Theory, Kripke's Objection, Functionalism

24 philosophy readings including classic texts (Descartes, Turing) and modern philosophy of mind (Searle, Block, Putnam, Churchlands, Kripke, Nagel, Chalmers, Jackson).

## Working with Session Files

When creating new session notes:
- Use timestamp format: `sessions/YYYY-MM-DD-HH-MM-SS.md`
- Document what was covered in that session
- Track knowledge gaps identified
- Note which readings were completed
- Plan next steps

Session files should be self-contained summaries that allow picking up where you left off.

So always read the most recent session files when starting in this directory.

## Reading Course Information

The markdown in `docs/` contains critical course information:
- Always check `dates.md` for upcoming deadlines
- `reading.md` shows the full reading list (24 texts)
- `welcome.md` may have recent instructor updates
- Part 1/2 markdown files show lecture structure

When analyzing course progress or planning, read these files to get current state.
