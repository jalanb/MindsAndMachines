## Learning Strategy

### Session Structure
Each study session should:
1. **Start:** Read most recent `sessions/*.md` file for context
2. **Focus:** Work on specific lecture/reading/concept
3. **Document:** Create new timestamped session file with:
   - What was covered
   - Key insights and connections
   - Knowledge gaps identified
   - Questions for further investigation
   - Next steps
4. **Update:** Mark progress in `TODO.md` and `PLAN.md`

### Engaging with Readings

**Two-tier approach:**
1. **MIT excerpts** (`readings/*.pdf`):
   - Start here for course-specific framing
   - Note MIT's talking points and emphasis
   - Use for efficient exam prep

2. **Full papers** (to be downloaded):
   - Read for deeper understanding
   - See full context of arguments
   - Understand responses and counterarguments
   - Essential for argument analysis assignments

**Reading workflow:**
- First pass: MIT excerpt → identify key concepts
- Second pass: Full paper → understand full argument
- Third pass: Session notes → connect to other readings/lectures

### Note-Taking Approach

**For lectures:**
- Summary of main points
- Key arguments in premise-conclusion form
- Questions raised
- Connections to readings

**For readings:**
- Author's main thesis
- Supporting arguments
- Objections considered
- My questions/thoughts
- Links to other readings/lectures

### Tracking Progress
- `TODO.md`: Task-level tracking with checkboxes
- `sessions/*.md`: Session-by-session narrative
- `PLAN.md`: Strategic overview (this file)
- Update all three regularly
